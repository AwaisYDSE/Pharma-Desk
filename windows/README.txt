PharmaDesk — pharmacy management
Developed by Awais Amin

ON THE MAIN SHOP PC (the "server"):
 1. Double-click "Start PharmaDesk Server".
    (First time it installs the free Node.js automatically if needed.)
 2. The browser opens. Create the OWNER account (this is you — it can never be deleted).
 3. Optional: double-click "Start automatically with Windows".
 4. Optional, recommended: install Tailscale (free, tailscale.com) on this PC and on
    the phones for a fixed, private address that works from anywhere.

ON PHONES AND OTHER PCs:
 1. Open the app link (shown in Settings on the server PC), tap "Install / Add to Home screen".
 2. Tap "Scan QR" and scan the QR code shown in Settings on the server PC.
 3. Type the 6-digit Server PIN shown on the server PC. Done.

Every device keeps a full copy of the shop's data. If the server PC is off, phones
still show everything and keep billing; it all syncs when the server is back.

Your data stays on YOUR PC (folder: %USERPROFILE%\PharmaDesk). Backups are made
automatically every 6 hours in %USERPROFILE%\PharmaDesk\backups.
